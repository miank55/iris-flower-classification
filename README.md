# 🌸 Iris Flower Classification

A Flask-based machine learning web app that predicts one of three Iris species from four flower measurements. It trains Logistic Regression, Decision Tree and K-Nearest Neighbours models, evaluates them on a held-out test set, and saves the best-performing estimator.

## Features
- Predict Setosa, Versicolor or Virginica from sepal/petal measurements.
- Display model confidence and class probability percentages.
- Train and compare three classification algorithms.
- Generate dataset CSV, pair plot, histograms, correlation heatmap and confusion matrix.
- Health endpoint at `/health` for deployment checks.
- Responsive Flask/Jinja frontend.

## Dataset
The classic Iris dataset from `sklearn.datasets.load_iris()`: 150 samples, 4 numeric features and 3 classes.

## Run locally (Windows PowerShell)

Use Python 3.10 or 3.11. Python 3.11 is recommended for the pinned dependencies.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
python app.py
```

Open **http://127.0.0.1:5000**.

If PowerShell blocks environment activation:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Enter these values in the form in the order shown to demonstrate each prediction.

## Model training and evaluation

```bash
python train_model.py
```

This command saves:
- `iris_model.pkl` — best estimator selected by held-out test accuracy
- `dataset/iris_data.csv` — dataset copy
- `images/pair_plot.png`
- `images/histogram.png`
- `images/heatmap.png`
- `images/confusion_matrix.png`

The split uses a fixed random seed for reproducible demonstration results. Accuracy is measured on the held-out split and should not be interpreted as a guarantee of real-world performance.

## Tests

Train the model first, then run:

```bash
pytest tests/ -v
```

## Deploy to Render

1. Create a new **Web Service** and connect this repository.
2. Runtime: Python 3.11.
3. Build command:

   ```bash
   pip install -r requirements.txt && python train_model.py
   ```

4. Start command:

   ```bash
   gunicorn app:app
   ```

5. Deploy. Check `https://YOUR-SERVICE.onrender.com/health`; a healthy deployment returns JSON with `"model_loaded": true`.

The build command trains and writes the model artifact into the service filesystem so the app can load it when the web process starts.
